# 脱・ドパガキ道場 (DopaDetox Dojo)

ショート動画（TikTok / Shorts / Reels）や過剰な刺激によって注意力や前頭葉の機能が低下した現代人（ドパガキ）が、科学的アプローチと禅メディテーションを通じて前頭葉を取り戻すための実践型Webアプリケーションです。

---

## 🚀 使い方

### 方法 1: ダブルクリックで直接開く
フォルダ内の `start.bat` をダブルクリック、または `index.html` をお好みのブラウザ（Chrome, Edge等）で直接開くだけで即座に動作します。

### 方法 2: ローカルHTTPサーバーで起動
```bash
cd C:\Users\akeer.AKERU\.gemini\antigravity\scratch\dopa-detox
python -m http.server 8080
```
ブラウザで `http://localhost:8080/` にアクセスします。

## 🛠️ 主な機能

1. **🩺 脳汁診断（ドパガキ度チェッカー）**
   - 10問の自己診断、レーダーチャート表示、判定ランク（SSS級〜仙人級）、𝕏（Twitter）シェア機能
2. **🚨 脳汁SOS（緊急ドーパミンスワップ）**
   - 衝動の波をやり過ごす90秒 Urge Surfing タイマー、ボックス呼吸ガイド、30秒オフライン行動ガチャ
3. **🧘 何もしない修行（デジタル沈黙）**
   - 1分・3分・5分の沈黙瞑想。マウス操作やタブ切り替えで即失敗する厳格な離脱防止機能付き
4. **📖 活字リハビリ（スローリーディング道場）**
   - ショート動画で短縮された読解力を回復。宮沢賢治やマルクス・アウレリウス等の名文をじっくり味わう読了テスト
5. **🛡️ 習慣・防壁（Habits & Hacks）**
   - 毎日のデトックス習慣チェックリスト、前頭葉EXPレベルアップ、スマホ画面モノクロ化などの物理環境ハック
6. **🧬 脳の科学（メカニズム解説）**
   - ドーパミン・ループの図解、ドーパミン vs セロトニンの比較表、回復タイムライン
7. **🌧️ Web Audio API による自然環境音**
   - 外部音声ファイル不要。雨音、波音、432Hz瞑想ドローン音、チベタンシンギングボウルをリアルタイム合成再生
